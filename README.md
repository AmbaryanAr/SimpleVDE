# SVDE — Simple Virtual Disk Editor

Утилита для создания и редактирования плоских образов виртуальных дисков
форматов `.img` и `.raw`.

**Версия:** 0.20.0 (альфа)

**Дисклеймер**
> Утилита находится на стадии альфа-тестирования и создана в учебных целях.
> Автор не несёт ответственности за потерю или повреждение данных.
> Перед работой с важными образами используйте проверенное ПО и делайте бэкапы.

## Возможности

- Создание образов дисков (`.img`) с таблицей разделов MBR или GPT
- Создание, удаление и изменение разделов
- Форматирование разделов в FAT32
- Работа с файлами внутри FAT32: копирование, удаление, создание каталогов, извлечение
- Проверка целостности FAT32
- Просмотр информации о диске, разделах и файловой системе
- Установка и чтение метки тома
- Реестр файлов в резервном кластере FAT32 (уникальная функция)
- Копирование раздела в отдельный raw-файл
- Поддержка raw-образов (без таблицы разделов)
- Интерактивная оболочка для работы с FAT32
- Кэширование FAT в памяти
- Кроссплатформенность: Windows 10/11, Linux Mint/Debian

## Сборка

### Linux и Windows (MSYS2 MinGW64)
```bash
make
```

### Быстрый старт
```bash
# Создать образ с MBR
simplevde --disk-create -file=disk.img -size=128M -table=mbr

# Создать раздел
simplevde --part-create -file=disk.img -part=1 -size=64M

# Форматировать в FAT32
simplevde --format -file=disk.img -part=1 -fs=fat32

# Скопировать файл в образ
simplevde --fs-copy -file=disk.img -part=1 -src=README.md -dest=/README.md

# Посмотреть содержимое
simplevde --fs-ls -file=disk.img -part=1

# Проверить целостность
simplevde --fs-check -file=disk.img -part=1 -level=full

# Интерактивная оболочка
simplevde --shell -file=disk.img -part=1
```

### Особенности запуска
| Среда | Примечание |
|-------|------------|
| Linux | `./simplevde ...` |
| Windows CMD | `simplevde.exe ...` |
| Windows PowerShell | `.\simplevde.exe --% ...` |
| Windows MSYS2 | `MSYS2_ARG_CONV_EXCL=* ./simplevde.exe ...` |

### Команды
Полный список команд с примерами: [doc/commands.txt](doc/commands.txt)

Основные категории:
- **disk** — создание и информация о диске
- **part** — работа с разделами
- **format** — форматирование
- **fs** — файловые операции, реестр, проверка
- **extract** — копирование раздела
- **shell** — интерактивная оболочка

### Реестр (резервный кластер FAT32)

Уникальная возможность — ведение реестра файлов в зарезервированном кластере FAT32.
Используется для хранения списка загрузочных файлов и быстрого доступа к ним.

| Команда | Описание |
|---------|----------|
| `--fs-reserve-init` | Инициализировать реестр |
| `--fs-reserve-ls` | Список записей |
| `--fs-reserve-add` | Добавить файл в реестр |
| `--fs-reserve-rm` | Удалить запись по имени |
| `--fs-reserve-clear` | Очистить реестр |
| `--fs-reserve-dump` | Hex-дамп реестра |
| `--fs-reserve-info` | Информация о реестре |
| `--fs-reserve-boot-set` | Назначить загрузочный файл |
| `--fs-reserve-boot-show` | Показать загрузочный файл |
| `--fs-reserve-boot-clear` | Сбросить загрузочный файл |

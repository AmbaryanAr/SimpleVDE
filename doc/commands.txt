===========================================
  SVDE — Simple Virtual Disk Editor
  Список команд
===========================================

Синтаксис:
  simplevde --<категория>-<команда> -<ключ>=<значение> ...

Параметр -part:
  -part=1, -part=2, ...  — номер раздела (начиная с 1)
  -part=raw              — образ без таблицы разделов

Параметр -size:
  Поддерживает суффиксы: K (килобайты), M (мегабайты), G (гигабайты)
  Примеры: 64M, 1G, 512K

===========================================
  Диск
===========================================

--disk-create -file=<путь> -size=<размер> [-table=mbr|gpt]
  Создать новый образ диска.
  -table необязателен (образ без таблицы разделов).

--disk-info -file=<путь>
  Показать информацию о диске и разделах.

--disk-read -file=<путь> -offset=<байт> -count=<байт>
  Прочитать байты и вывести hex-дамп.

--disk-read-s -file=<путь> -offset=<секторов> -count=<секторов>
  Прочитать секторы и вывести hex-дамп.

===========================================
  Разделы
===========================================

--part-create -file=<путь> -part=<номер> -size=<размер> [-type=<тип>]
  Создать раздел. Тип по умолчанию: linux.
  Тип можно указать именем (fat32, linux, swap, efi, ntfs) или hex-кодом (0x0B).

--part-delete -file=<путь> -part=<номер>
  Удалить раздел.

--part-set-type -file=<путь> -part=<номер> -type=<тип>
  Изменить тип раздела.

--part-set-active -file=<путь> -part=<номер>
  Установить флаг активности (только MBR).

--part-set-inactive -file=<путь> -part=<номер>
  Снять флаг активности (только MBR).

===========================================
  Форматирование
===========================================

--format -file=<путь> -part=<номер|raw> -fs=fat32
  Форматировать раздел в FAT32.
  После форматирования автоматически обновляет тип раздела.

===========================================
  Файловая система
===========================================

--fs-ls -file=<путь> -part=<номер|raw> [-path=<путь>]
  Список файлов и каталогов. По умолчанию — корень.

--fs-copy -file=<путь> -part=<номер|raw> -src=<хост-файл> -dest=<путь-в-ФС>
  Копировать файл с хоста в образ.
  -dest должен быть абсолютным путём, включая имя файла.

--fs-extract -file=<путь> -part=<номер|raw> -src=<путь-в-ФС> -dest=<хост-путь>
  Извлечь файл из образа на хост.

--fs-mkdir -file=<путь> -part=<номер|raw> -path=<путь>
  Создать каталог.

--fs-rm -file=<путь> -part=<номер|raw> -path=<путь>
  Удалить файл.

--fs-rmdir -file=<путь> -part=<номер|raw> -path=<путь>
  Удалить пустой каталог.

--fs-tree -file=<путь> -part=<номер|raw> [-path=<путь>]
  Показать дерево каталогов.

--fs-label -file=<путь> -part=<номер|raw> [-name=<метка>]
  Без -name — показать метку тома.
  С -name — установить новую метку (до 11 символов).

--fs-info -file=<путь> -part=<номер|raw>
  Показать подробную информацию о файловой системе:
  геометрия, layout, занято/свободно.

--fs-check -file=<путь> -part=<номер|raw> [-level=quick|full]
  Проверить целостность файловой системы.
  quick — быстрая проверка (BPB, FSInfo).
  full  — полная проверка (FAT, цепочки кластеров).

===========================================
  Реестр (резервный кластер FAT32)
===========================================

Реестр хранится в зарезервированном кластере, номер которого
записан в BPB по смещению 52. Используется для ведения списка
файлов и указания загрузочного файла.

--fs-reserve-init -file=<путь> -part=<номер|raw>
  Инициализировать реестр (выделить кластер, записать номер в BPB).

--fs-reserve-ls -file=<путь> -part=<номер|raw>
  Показать все записи реестра.

--fs-reserve-add -file=<путь> -part=<номер|raw> -path=<путь-к-файлу>
  Добавить файл в реестр (файл должен существовать в ФС).

--fs-reserve-rm -file=<путь> -part=<номер|raw> -name=<имя>
  Удалить запись по имени.

--fs-reserve-clear -file=<путь> -part=<номер|raw>
  Очистить все записи.

--fs-reserve-dump -file=<путь> -part=<номер|raw>
  Hex-дамп резервного кластера.

--fs-reserve-info -file=<путь> -part=<номер|raw>
  Информация о реестре: размер, слоты, занято/свободно.

--fs-reserve-boot-set -file=<путь> -part=<номер|raw> -name=<имя>
  Назначить файл из реестра загрузочным.

--fs-reserve-boot-show -file=<путь> -part=<номер|raw>
  Показать текущий загрузочный файл.

--fs-reserve-boot-clear -file=<путь> -part=<номер|raw>
  Сбросить указатель загрузочного файла.

===========================================
  Извлечение раздела
===========================================

--extract-copy -file=<путь> -part=<номер> -output=<файл>
  Копировать раздел в отдельный raw-файл.
  Раздел остаётся в исходном образе.

===========================================
  Загрузочный код
===========================================

--mbr-write -file=<путь> -src=<файл-кода>
  Записать загрузочный код в MBR (первые 446 байт).

--bpb-write -file=<путь> -part=<номер|raw> -src=<файл-кода>
  Записать загрузочный код в BPB раздела FAT32 (смещение 90).

===========================================
  Интерактивная оболочка
===========================================

--shell -file=<путь> -part=<номер|raw>
  Запустить интерактивную оболочку для работы с FAT32.

  Команды оболочки:
    ls [path]               — список файлов
    cd [path]               — смена каталога
    pwd                     — текущий каталог
    mkdir <path>            — создать каталог
    rmdir <path>            — удалить пустой каталог
    rm <path>               — удалить файл
    copy <host> <dest>      — копировать файл в образ
    tree [path]             — дерево каталогов
    reserve init            — инициализировать реестр
    reserve ls              — список записей реестра
    reserve add <path>      — добавить в реестр
    reserve rm <name>       — удалить из реестра
    reserve clear           — очистить реестр
    reserve dump            — дамп реестра
    reserve info            — инфо реестра
    reserve boot set <name> — назначить загрузочный
    reserve boot show       — показать загрузочный
    reserve boot clear      — сбросить загрузочный
    exit                    — выход
    help, ?                 — справка

===========================================
  Справка
===========================================

--help, -h
  Полная справка по всем категориям.

--version, -v
  Версия программы.

--<категория> help
  Справка по конкретной категории (например: --fs help).
